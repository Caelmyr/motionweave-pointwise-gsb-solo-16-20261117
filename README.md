# MotionWeave 动态影像编排

以有时长的源图像序列构成多轨道合成。图像是全部处理和交付的主体。打开根页面后创建合成演示，或创建空工程上传PNG/JPEG帧。演示为合成素材，不是真实拍摄。

源时间和合成时间分开：片段入点/出点以源秒表示，片段长度以合成秒表示，裁切/倒放/变速都映射到同一个源时间；运动和遮罩关键帧都在源时间域。源帧区间左闭右开，序列末端取最后帧；片段区间左闭右开。遮罩顶点是源图像归一化坐标，同一遮罩各关键帧必须有相同顶点数及相同对应顺序。运动以画布像素平移、几何尺度和最短旋转弧插值。图层按轨道编号及稳定ID从下向上混合。

透明像素先转换到线性光、预乘透明度再空间重采样；遮罩在源坐标计算后随图像一起变换。预览、捕获和PNG序列都用相同渲染器。捕获保存不可变文档和对应帧，之后修改工程或替换源帧不改旧捕获。渲染时发生内容变更会拒绝发布旧结果。撤销/重做只回退编辑内容，不删除历史捕获。ZIP含PNG、联系表、文档、逐帧图层来源清单及时间CSV。

支持创建工程、序列上传、单帧替换、多轨叠加、入出点裁切、时长变速、倒放、片段移动、分割、复制、普通/波纹删除、关键帧运动、动态多边形遮罩及羽化、三种混合模式、透明背景、时间检查、撤销重做、版本捕获与ZIP交付。源时间模型不会做光流插帧或声音处理。所有图片整帧加载，最多24源、48片段、120帧/源、2400万像素/输入，画布最高1920×1080、输出最多3600帧；已验证的演示为480×270、32输出帧，不承诺最大规格实时速度。

启动：`docker compose -p solo19-motionweave up -d --build`，访问 `http://localhost:18919`。数据存独立命名卷`solo19-motionweave-data`，删除容器不会删除卷。停止使用`docker compose -p solo19-motionweave stop`。需要Python3.11及requirements.txt锁定依赖。单进程多线程由进程内锁串行修改工程。

`/prepare`是完整自有图像准备工具，`image_lab`从同工作区solo_18按字节复用，负责上传、配准、合成、遮罩、校正、结果和素材导入导出等准备工作，准备结果可下载后导入序列。本产品新增motionweave包负责时空编排、线性光渲染、编辑事务与序列交付，未复用旧业务主模块。后台统计只包含image_lab和motionweave，排除页面、脚本、文档、生成数据及第三方代码。
